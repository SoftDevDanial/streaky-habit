# S1 First visit

**Golden** `today-empty.html`
**Inventory** S1, no habits yet (C1, C5)

## Intent
An empty screen that says what to do. The field waits where it always is.

## What the golden shows
K1's layout with no habits. The list frame holds the empty state (a 96 px dotted orbit round a `--track` core, then the lead and the line). The band draws every past day as one thin `--ring` circle with its number, today with the ink circle, Sunday 11 October empty. The legend is None, one empty ring, All. On a phone the Overview button carries one empty ring.

## Exact copy

| Element | Text |
|---|---|
| Empty lead | No habits yet. |
| Empty line | Add one you want to do every day. |
| Day names | "Mon 20 Jul, 0 of 0 habits" and so on |
| Overview button name | Overview, today 0 of 0 habits done |
| Field | New habit, Add |

## Links
None out. The Overview button and Year would open P3 and P4 with empty rings, which have no golden of their own.
