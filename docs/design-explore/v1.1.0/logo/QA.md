Swap rule, favicon-src for the tab icon, the 16 grid path below 28 px, never mark-src under 24 px. (Superseded, the first version said the favicon sits on its own `#18191C` tile, the owner then ruled no tile.) Re-rendered at 1440 x 900, no console errors, no network, no clipped text.

**T6 no tile, 2026-10-11 (owner's ruling).** The orchestrator removed the `#18191C` rect from `favicon-src`, the tab icon data URI and the sprite, and shows the favicons on a dark tab (`#35363A`) and a white tab.
