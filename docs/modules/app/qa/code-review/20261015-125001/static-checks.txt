## 10. What the test-side tree and ring readers compare (conftest.py)
_CANON_JS (canon_tree) returns [node.localName, attributes, text, children]; _RING_PARTS_JS returns node.localName with classes and
geometry attributes. Neither reads namespaceURI, so an svg, path, circle or text made in the HTML namespace (which draws nothing)
reads the same as the real one. The 1.0 suite compared namespaces (code review WR-01, solver commit e8bd2c9); that helper,
canonical_pair, left with the 1.0 files at task 12.
